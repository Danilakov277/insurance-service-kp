# Курсовой проект: ПС для поддержки процесса оказания страховых услуг населению

Дисциплина «Программирование сетевых приложений», БГУИР, кафедра ЭИ. Автор: Балащенко К.Р., гр. 414351.
Руководитель: ст. преподаватель Сторожев Д.А.

Клиент-серверное приложение «Страховой сервис» на Java: многопоточный сервер (сокеты, пул потоков,
JDBC, PostgreSQL) и оконный клиент на Swing для трёх ролей — клиент, страховой агент, администратор.

## Состав репозитория

| Папка / файл | Что внутри |
|---|---|
| `common/`, `server/`, `client/` | исходный код (Maven, Java 8+) и модульные тесты |
| `database/` | скрипт создания БД (`01_schema.sql`) и демонстрационные данные (`02_demo_data.sql`) |
| `create-database.bat`, `run-server.bat`, `run-client.bat` | запуск в Windows |
| `server.properties` | настройки сервера (порт, число потоков, подключение к БД) |
| `docs/` | пояснительная записка (`ПЗ_КП_ПСП_Балащенко.docx`, `.pdf`) и скрипты её сборки |
| `graphics/` | графическая часть, формат А4: чертежи Д2 (IDEF0) и Д3 (схема алгоритма), плакаты Д5 (3 листа), ведомость документов Д1 |
| `diagrams/` | диаграммы (PNG/SVG): BPMN 2.0, IDEF0, IDEF1X, UML, схемы алгоритмов, архитектура |
| `uml/` | исходники UML-диаграмм (PlantUML) |
| `screenshots/` | снимки окон программы для сквозного тестового примера |
| `tools/` | генераторы диаграмм, чертежей и плакатов |
| `design.md` | проектные решения: роли, варианты использования, БД, алгоритмы, архитектура |

## Быстрый запуск (Windows)

1. Установить PostgreSQL 16 и JRE 8 или новее.
2. `create-database.bat` — создаёт БД `insurance` и загружает демонстрационные данные.
3. Собрать проект: `mvn clean package` (готовые архивы — `server/target/insurance-server.jar`, `client/target/insurance-client.jar`).
4. `run-server.bat`, затем `run-client.bat`.

Учётные записи демонстрационных данных: администратор `admin / admin123`, агент `kovaleva / agent123`,
клиент `ivanov / client123`.

## Пояснительная записка

Записка собирается скриптом `docs/make_pz.sh` (Linux, LibreOffice, Node.js с пакетом `docx`):
текст — `docs/content*.py`, вёрстка — `docs/build.js`, перенос таблиц — `docs/autosplit.py`,
содержание и счётчики реферата — `docs/postprocess.py`. Графическая часть — `tools/make_graphics.py`.
