# Курсовой проект: ПС для поддержки процесса оказания страховых услуг населению

Дисциплина «Программирование сетевых приложений», БГУИР. Автор: Балащенко К.Р., гр. 414351.

| Папка | Что внутри |
|---|---|
| `docs/` | пояснительная записка (`ПЗ_КП_ПСП_Балащенко.docx`, `.pdf`) и скрипты её сборки |
| `graphics/` | графическая часть (чертежи и плакаты, PDF, A4) |
| `diagrams/` | все диаграммы (PNG/SVG): IDEF0, IDEF1X, UML |
| `uml/` | исходники UML-диаграмм (PlantUML) |
| `tools/` | генераторы диаграмм и чертежей |
| `design.md` | проектные решения: роли, варианты использования, БД, алгоритмы, архитектура |

Программная часть (сервер и клиент на Java, PostgreSQL) появится в папках `common/`, `server/`, `client/`.
